## Start Heist Plan Screen

This app includes a themed "Start Heist Plan" flow:

- Open the menu screen and tap "Start the Heist" to navigate.
- The plan page shows a header, live plan meta, and animated steps.
- Use "Initiate Heist" to simulate arming the plan or "Back to Menu" to return.

Files:
- [lib/ui/pages/heist_menu_page.dart](lib/ui/pages/heist_menu_page.dart): entry button navigates to the plan.
